# Learning-Enhanced Robust Adaptive Control of Networked Robotic Systems

Research project investigating learning-enhanced robust adaptive control of a 2-DOF robotic manipulator under sensor and communication uncertainty.

## Methods

- Adaptive Sliding Mode Control (ASMC)
- Radial Basis Function Neural Network (RBFNN)
- MATLAB-based numerical simulation

## Uncertainty Scenarios

- Sensor noise
- Sensor degradation
- Communication delay
- Packet loss
- External disturbances
- Changing dynamics
- Combined uncertainty

## Files

- `Research_Paper.pdf` — research paper
- `MATLAB_Code.zip` — MATLAB source code, training data, trained models, and experiment scripts
